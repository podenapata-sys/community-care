# community-care

Demo landing page and online booking for Community Care Hospital & Diagnostic, Tetultola Mor, Khulna.

- `index.html`: single-page site, Bangla by default with an English toggle.
- Fill in real data in the `CONFIG` block at the bottom of `index.html` (phones, WhatsApp, services, doctors, booking webhook).
- Items outlined in dashed orange are placeholders awaiting details from the hospital.
