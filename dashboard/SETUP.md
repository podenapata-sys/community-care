# সিরিয়াল ড্যাশবোর্ড চালু করার নিয়ম (Supabase)

সময় লাগবে প্রায় ২০ মিনিট। খরচ ০ টাকা: Supabase-এর ফ্রি প্ল্যানই এই হাসপাতালের জন্য যথেষ্ট।

ডেটাবেস যুক্ত না থাকলে ওয়েবসাইট আর ড্যাশবোর্ড দুটোই **ডেমো মোডে** চলে। ড্যাশবোর্ডে নমুনা ডেটা দেখায়, আর ওয়েবসাইটের ফর্ম কিছু সেভ করে না। নিচের ধাপগুলো করলে সব আসল হয়ে যাবে।

---

## ১. Supabase প্রজেক্ট খুলুন
1. **supabase.com**-এ যান → **Start your project** → GitHub বা ইমেইল দিয়ে সাইন আপ করুন।
2. **New project** চাপুন:
   - Name: `community-care`
   - Database password: শক্ত একটা পাসওয়ার্ড দিন, তারপর **কোথাও লিখে রাখুন**।
   - Region: **Southeast Asia (Singapore)**। বাংলাদেশ থেকে এটাই সবচেয়ে কাছে।
3. প্রজেক্ট তৈরি হতে ১–২ মিনিট লাগবে।

## ২. ডেটাবেস তৈরি করুন
1. বাম মেনু থেকে **SQL Editor** → **New query**।
2. রেপোর `supabase/schema.sql` ফাইলের পুরো লেখা কপি করে পেস্ট করুন।
3. **Run** চাপুন। নিচে "Success. No rows returned" দেখালে কাজ হয়ে গেছে।

এতে যা তৈরি হয়:
- `bookings` টেবিল: সব সিরিয়াল এখানে জমা হবে।
- প্রতি ডাক্তার ও প্রতি দিনের জন্য আলাদা সিরিয়াল নম্বর, যা স্বয়ংক্রিয়ভাবে বসে।
- নিরাপত্তা নিয়ম: রোগীরা শুধু সিরিয়াল পাঠাতে পারবেন, কারো ডেটা দেখতে পারবেন না।
- স্প্যাম আটকানো: একই নম্বর থেকে একদিনে সর্বোচ্চ ৩টি সিরিয়াল।
- লাইভ নোটিফিকেশন।

## ৩. বাইরের লোকের সাইন আপ বন্ধ করুন
**Authentication → Sign In / Providers → Email** → **"Allow new users to sign up"** বন্ধ করুন।
এতে শুধু আপনি যাদের অ্যাকাউন্ট বানিয়ে দেবেন, তারাই ড্যাশবোর্ডে ঢুকতে পারবেন।

## ৪. রিসেপশনের জন্য লগইন তৈরি করুন
**Authentication → Users → Add user → Create new user**:
- Email: রিসেপশনের ইমেইল (যেমন `reception.communitycare@gmail.com`)
- Password: শক্ত পাসওয়ার্ড
- ✅ **Auto Confirm User** টিক দিন

প্রতিটি স্টাফের জন্য আলাদা অ্যাকাউন্ট বানানো ভালো।

## ৫. ওয়েবসাইটের সাথে যুক্ত করুন
**Project Settings → API** থেকে দুটো জিনিস কপি করুন:
- **Project URL** (যেমন `https://abcdefgh.supabase.co`)
- **anon public** key

এগুলো `assets/config.js`-এ বসান:
```js
window.APP_CONFIG = {
  supabaseUrl: "https://abcdefgh.supabase.co",
  supabaseAnonKey: "eyJhbGciOi..."
};
```
> ⚠️ শুধু **anon public** key ব্যবহার করবেন। **service_role** key কখনো ওয়েবসাইটে দেবেন না। ওটা দিয়ে সব ডেটা পড়া ও মোছা যায়।

ফাইল সেভ করে কমিট ও পুশ করুন, তারপর সাইট আবার ডিপ্লয় করুন।

## ৬. টেস্ট করুন
1. ড্যাশবোর্ড খুলুন (`/dashboard/`) → রিসেপশনের ইমেইল ও পাসওয়ার্ড দিয়ে লগইন করুন।
2. ব্রাউজার নোটিফিকেশনের অনুমতি চাইলে **Allow** দিন।
3. অন্য একটা ফোন থেকে ওয়েবসাইটে একটা সিরিয়াল বুক করুন।
4. ড্যাশবোর্ডে **শব্দ + পপআপ** আসবে, আর সিরিয়ালটা তালিকায় দেখা যাবে। ✅
5. **WhatsApp কনফার্ম** চাপলে রোগীর WhatsApp-এ কনফার্মেশন মেসেজ তৈরি হয়ে খুলবে। শুধু **Send** চাপতে হবে।

## রিসেপশনের জন্য দৈনিক ব্যবহার
- সকালে ড্যাশবোর্ড খুলে রাখুন। নতুন সিরিয়াল এলেই শব্দ হবে।
- **নতুন** সিরিয়াল → **WhatsApp কনফার্ম** চাপুন (স্ট্যাটাস নিজে থেকেই "কনফার্ম" হয়ে যাবে)।
- রোগী এলে → **★ এসেছেন**।
- ফোনে বা কাউন্টারে আসা রোগী → **+ নতুন সিরিয়াল**। পরের সিরিয়াল নম্বর নিজে থেকেই বসবে।
- ডাক্তারের দিনের তালিকা → ডাক্তার বেছে নিয়ে **🖨 প্রিন্ট**।
- হিসাবের জন্য → **⬇ Excel**।

## ফ্রি প্ল্যানের সীমা
- ৫০০ MB ডেটাবেস: বছরে লাখের বেশি সিরিয়াল রাখা যাবে।
- ৭ দিন কোনো ব্যবহার না হলে Supabase প্রজেক্ট **pause** করে দেয়। প্রতিদিন সিরিয়াল এলে এটা হবে না। Pause হলে Supabase ড্যাশবোর্ড থেকে **Restore** চাপলেই আবার চালু হয়।
