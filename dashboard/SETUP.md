# Firebase দিয়ে ওয়েবসাইট ও সিরিয়াল ড্যাশবোর্ড চালু করার নিয়ম

সময় লাগবে প্রায় ৩০ মিনিট। খরচ ০ টাকা: Firebase-এর ফ্রি **Spark** প্ল্যানই যথেষ্ট, কোনো ক্রেডিট কার্ড লাগবে না।

Firebase যুক্ত না থাকলে ওয়েবসাইট আর ড্যাশবোর্ড **ডেমো মোডে** চলে: নমুনা ডেটা দেখায়, কিছু সেভ হয় না।
নিচের ধাপগুলো শেষ করলে সব আসল হয়ে যাবে।

---

## ১. Firebase প্রজেক্ট খুলুন
1. **console.firebase.google.com**-এ যান, তারপর আপনার Gmail দিয়ে লগইন করুন।
2. **Create a project** চাপুন, নাম দিন `community-care-khulna`।
3. Google Analytics জিজ্ঞেস করলে বন্ধ রাখতে পারেন। তারপর **Create project** চাপুন।

## ২. Web app যোগ করে config কপি করুন
1. প্রজেক্টের হোম পেজে **</>** (Web) আইকন চাপুন।
2. App nickname দিন `website`। **"Also set up Firebase Hosting"** টিক দিন, তারপর **Register app**।
3. স্ক্রিনে `firebaseConfig` দেখাবে। এর ৪টা মান `assets/config.js`-এ বসান:
```js
window.APP_CONFIG = {
  firebase: {
    apiKey: "AIzaSy....",
    authDomain: "community-care-khulna.firebaseapp.com",
    projectId: "community-care-khulna",
    appId: "1:1234:web:abcd"
  }
};
```
> এই মানগুলো গোপন নয়। এগুলো সব ভিজিটরের ব্রাউজারেই যায়। ডেটা সুরক্ষিত থাকে `firestore.rules`-এর নিয়ম দিয়ে।
> তবে **service account JSON** (ধাপ ৭) কখনো কোডে বা চ্যাটে দেবেন না।

`.firebaserc` ফাইলে `community-care-khulna`-এর জায়গায় আপনার আসল projectId বসান।

## ৩. ডেটাবেস (Firestore) চালু করুন
1. বাম মেনু থেকে **Build → Firestore Database → Create database**।
2. Location: **asia-south1 (Mumbai)**। বাংলাদেশ থেকে এটাই সবচেয়ে কাছে। ⚠️ পরে বদলানো যায় না।
3. **Start in production mode** বেছে নিন, তারপর **Create**।
4. **Rules** ট্যাবে যান। রেপোর `firestore.rules` ফাইলের পুরো লেখা পেস্ট করে **Publish** চাপুন।

এই নিয়মগুলো যা করে:
- রোগীরা শুধু সিরিয়াল পাঠাতে পারেন, কারো ডেটা দেখতে পারেন না।
- প্রতি ডাক্তার ও প্রতি দিনের জন্য আলাদা সিরিয়াল নম্বর বসে (১, ২, ৩…), কেউ নম্বর জাল করতে পারে না।
- একই ফোন নম্বর থেকে একদিনে সর্বোচ্চ ৩টি সিরিয়াল, তাই স্প্যাম করা যায় না।
- শুধু অনুমোদিত স্টাফ সিরিয়াল দেখতে ও স্ট্যাটাস বদলাতে পারেন। কেউ সিরিয়াল মুছতে পারেন না।

## ৪. স্টাফ লগইন চালু করুন
1. **Build → Authentication → Get started**।
2. **Sign-in method** ট্যাব থেকে **Email/Password** চালু করুন, তারপর **Save**।
3. **Settings** ট্যাবে যান। **User actions**-এ **"Enable create (sign-up)"** টিক **তুলে দিন**, তারপর **Save**।
   এতে বাইরের কেউ নিজে অ্যাকাউন্ট খুলতে পারবে না।
4. **Users** ট্যাব থেকে **Add user**। রিসেপশনের ইমেইল ও শক্ত পাসওয়ার্ড দিন।
5. নতুন ইউজারের **User UID** কপি করুন (যেমন `kT9x...`)।

## ৫. স্টাফকে অনুমতি দিন (খুব জরুরি)
লগইন থাকলেই ড্যাশবোর্ড খুলবে না। ইউজারকে স্টাফ তালিকায় যোগ করতে হবে:
1. **Firestore Database → Data → + Start collection**।
2. Collection ID দিন `staff`, তারপর **Next**।
3. Document ID-তে ধাপ ৪-এর **User UID** পেস্ট করুন।
4. Field: `name` → string → `Reception`। তারপর **Save**।

প্রতিটি নতুন স্টাফের জন্য ধাপ ৪ ও ৫ আবার করুন। কাউকে বাদ দিতে চাইলে `staff` থেকে তার ডকুমেন্ট মুছে দিন।

## ৬. টেস্ট করুন (লোকাল কম্পিউটারে)
1. রেপো ফোল্ডারে `npx serve .` চালান, তারপর ব্রাউজারে দেখানো ঠিকানা খুলুন।
2. ওয়েবসাইটে একটা সিরিয়াল বুক করুন। **"আপনার সিরিয়াল নম্বর: 1"** দেখালে কাজ হয়ে গেছে ✅
3. `/dashboard/` খুলে রিসেপশনের ইমেইল দিয়ে লগইন করুন। সিরিয়ালটা দেখা যাবে।
4. অন্য ফোন থেকে আরেকটা বুক করুন। ড্যাশবোর্ডে **শব্দ + পপআপ** আসবে।

## ৭. ওয়েবসাইট লাইভ করুন (Firebase Hosting)

**সহজ পথ (একবার, নিজের কম্পিউটার থেকে):**
```bash
npm install -g firebase-tools
firebase login
firebase deploy --only hosting,firestore:rules
```
সাইট লাইভ হবে `https://<projectId>.web.app`-এ।

**অটো-ডিপ্লয় (প্রতিবার GitHub-এ পুশ করলে নিজে থেকেই লাইভ হবে):**
1. Firebase console → **Project settings → Service accounts → Generate new private key**। একটা JSON ফাইল ডাউনলোড হবে।
2. GitHub রেপো → **Settings → Secrets and variables → Actions**:
   - **Secrets → New repository secret**: নাম `FIREBASE_SERVICE_ACCOUNT`, মান হিসেবে পুরো JSON ফাইলের লেখা।
   - **Variables → New repository variable**: নাম `FIREBASE_PROJECT_ID`, মান আপনার projectId।
3. এরপর `main`-এ প্রতিটি পুশে `.github/workflows/firebase-deploy.yml` সাইট ডিপ্লয় করবে।
4. JSON ফাইলটা কম্পিউটার থেকে মুছে দিন বা নিরাপদে রাখুন। **কাউকে দেবেন না।**

## ৮. নিজের ডোমেইন যুক্ত করুন (ঐচ্ছিক)
**Hosting → Add custom domain** → ডোমেইন লিখুন (যেমন `communitycarekhulna.com`) → দেখানো DNS রেকর্ড ডোমেইন প্রোভাইডারে বসান।
SSL (https) Firebase নিজেই দেবে, ফ্রি।

## রিসেপশনের দৈনিক ব্যবহার
- সকালে ড্যাশবোর্ড খুলে রাখুন। নতুন সিরিয়াল এলেই শব্দ হবে।
- **নতুন** সিরিয়ালে **WhatsApp কনফার্ম** চাপুন। স্ট্যাটাস নিজে থেকেই "কনফার্ম" হবে।
- রোগী এলে **★ এসেছেন** চাপুন।
- ফোনে বা কাউন্টারে আসা রোগীর জন্য **+ নতুন সিরিয়াল**:
  - আগে **মোবাইল নম্বর** লিখুন। রোগী আগে এসে থাকলে নাম, বয়স আর আগের ভিজিটগুলো নিজে থেকেই দেখাবে। এক নম্বরে পরিবারের কয়েকজন থাকলে নাম বেছে নিন।
  - রোগীর মোবাইল না থাকলে (বয়স্ক রোগী ইত্যাদি) ঘরটা **খালি রাখুন**। তালিকায় "ফোন নেই" দেখাবে।
  - ডাক্তার বাছলে **ভিজিট ফি** নিজে থেকেই বসে যায়, দরকার হলে বদলান। টাকা নিয়ে থাকলে **"ফি আদায় হয়েছে"** টিক দিন।
- পরে টাকা নিলে সিরিয়ালের পাশে **💳 ফি আদায়** চাপুন। ভুল হলে সবুজ "আদায় ✓" চাপলে বাতিল হবে।
- **রিপোর্ট** ট্যাবে আজকের আর গত ৩০ দিনের মোট আদায় দেখা যায়।
- ভুল বা ডুপ্লিকেট সিরিয়াল মুছতে **🗑** চাপুন। সিরিয়ালটা **৩০ দিন "🗑 বিন" ট্যাবে** থাকবে, কে আর কখন মুছেছেন সেটাও লেখা থাকবে। এর মধ্যে **↺ ফিরিয়ে আনুন** চাপলে আবার তালিকায় চলে আসবে। ৩০ দিন পর স্থায়ীভাবে মুছে যায়।
- রোগী না এলে মুছবেন না, **✕ বাতিল** করুন। বাতিলের হিসাব রিপোর্টে থাকে, মোছা সিরিয়ালের থাকে না।
- দিনের তালিকা দরকার হলে **🖨 প্রিন্ট**, হিসাবের জন্য **⬇ Excel**।

## ফ্রি প্ল্যানের সীমা (Spark)
- প্রতিদিন ৫০,০০০ রিড ও ২০,০০০ রাইট। দিনে কয়েকশো সিরিয়ালের জন্য অনেক বেশি।
- ১ GB ডেটাবেস, যাতে বহু বছরের সিরিয়াল ধরবে।
- Hosting: ১০ GB স্টোরেজ, মাসে ৩৬০ MB/দিন ট্রান্সফার।

## ডেভেলপারদের জন্য: টেস্ট
`tests/` ফোল্ডারে Firestore rules ও end-to-end টেস্ট আছে (Firebase emulator দিয়ে চলে):

```bash
cd tests && npm install && npm run test:rules
```

## ডাক্তারের লগইন (শুধু নিজের রোগী দেখবেন)
ডাক্তার লগইন করলে **শুধু তাঁর নিজের সিরিয়াল** দেখবেন, অন্য ডাক্তারের রোগী দেখতে পারবেন না। এটা ডেটাবেসের নিয়মে আটকানো, শুধু স্ক্রিনে লুকানো নয়। ডাক্তার শুধু **★ এসেছেন** চাপতে পারবেন: নতুন সিরিয়াল, ফি, বাতিল বা মোছার অপশন তাঁর থাকবে না।

**প্রথমবার (একবারই):** নতুন নিয়ম আর ইনডেক্স লাইভ করুন:
```
firebase deploy --only firestore:rules,firestore:indexes,hosting
```
ইনডেক্স তৈরি হতে ৫–১০ মিনিট লাগতে পারে।

**প্রতিটা ডাক্তারের জন্য:**
1. **Authentication → Users → Add user**: ডাক্তারের Gmail আর একটা অস্থায়ী পাসওয়ার্ড দিন।
2. নতুন লাইনের **User UID** কপি করুন।
3. **Firestore Database → `doctors`** কালেকশন (প্রথমবার **Start collection** দিয়ে বানাতে হবে) → **Add document**:
   - Document ID: UID পেস্ট করুন
   - Field `doctor` (string): ডাক্তারের নাম **হুবহু** যেমন ড্যাশবোর্ডের ডাক্তার তালিকায় আছে (বানান, Dr., ডট সব একই)
4. **Authentication → Users**-এ ওই লাইনের **⋮ → Reset password** চাপুন। ডাক্তারের Gmail-এ লিংক যাবে, সেখান থেকে নিজের পাসওয়ার্ড দেবেন।

> ⚠️ একই অ্যাকাউন্ট `staff` আর `doctors` দুটোতে থাকলে স্টাফ হিসেবে পূর্ণ অ্যাক্সেস পাবে। ডাক্তারকে শুধু `doctors`-এ রাখুন।
> নাম ভুল হলে লগইন হবে কিন্তু কোনো রোগী দেখাবে না। তখন `doctor` ফিল্ডের বানান মিলিয়ে নিন।
> উদাহরণ: dr.tanmoyankhimallick01-এর `doctor` ফিল্ড হবে `Dr. Tonmoy Mollik` (আগের "Tanmoy Mallick" নয়)।
